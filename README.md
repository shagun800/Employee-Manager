# Employee Management System

A simple console-based Employee Management System developed in Java. The project allows users to add employees, view all employees, and search for employees by department.

## Features

* Add a new employee
* Display all employees
* Search employees by department
* Console-based menu
* Uses `ArrayList` to store employee objects

## Project Structure

```text
Employee-Management-System/
│
├── src/
│   ├── Main.java
│   └── Employee.java
│
├── .gitignore
└── README.md
```

## Employee Details

Each employee contains:

* Name
* ID
* Department

## Menu

```text
===== Employee Management System =====
1. Add Employee
2. List All Employees
3. Search by Department
4. Exit
```

## Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Scanner

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project in a Java-compatible IDE.

3. Run `Main.java` from the `src` folder.

4. Use the console menu to manage employee records.
